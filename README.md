## 提交问题规范

开发者在提交 Issue 前请注意以下事项

- 请先搜索查看其他开发者已提出的问题，避免提交重复的 Issue
- 请仔细阅读下方的格式规范与字段说明，按规范提交需求

### 格式规范表格字段说明

- 开发者名称（可选）：对应开发者名字

- 大类（必须）：接口 / 事件 / MCS / 其他

- 接口类型（可选）：服务端/客户端/其他

- SDK需求背景（必须）：详细描述为什么需要这么一个SDK，起因是什么 **（这里描述越详细，越会有助于官方进行采纳）**

- 替代方案（可选）：是否有替代方案，有则详细描述替代方案，以及可能会出现的问题、能否完全解决当前需求

- SDK用途（必须）：详细描述需要SDK的用途，想要实现什么效果 **（这里描述越详细，越会有助于官方进行采纳）**

## 官方回复

官方会对需求进行筛选排期，请耐心等待 Issue 中的官方回复。未被纳入当前排期的需求也会予以记录，并在合适时机纳入后续开发计划。
